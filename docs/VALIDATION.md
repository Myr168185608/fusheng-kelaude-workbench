底座变更：
- 插件可以声明两个固定位置的小控件（`contributes.sidebar`、`contributes.composer`），由宿主绘制、插件更新内容，没有自己的 iframe，也不需要新权限：
  - 侧边栏入口：位于左侧边栏底部，点击打开插件面板，必须同时声明 `panel`。插件用 `wb.ui.setSidebar({ subtitle, tone })` 更新副标题。
  - 输入框选择器：位于模型选择旁，必须同时声明 `background`。后台界面用 `wb.composer.setPicker()` 提供选项、默认值和各会话的当前值。用户改选后，插件收到 `composer:change` 事件，并用 `wb.composer.reply()` 回复；回复被拒绝时退回原值并提示原因。当前会话运行中、等待审批或终端占用时，选择器锁定。
- 还没有会话的新对话里做的选择由页面暂存，随第一条消息以 `choices` 发出，只发一次。服务端检查格式后，只把属于该插件的那一项作为 `request.choice` 交给它的 `beforeRun`。
- 新事件 `runtime`（需要 `backend` 权限）：可信后端调用 `runtimeChanged()` 后通知该插件的各个界面重新读取。
- 部署脚本生成的 systemd unit 不再给 `WorkingDirectory=` 加引号。systemd 247（Debian 11）不认带引号的路径，会把整个 unit 判为 bad-setting。路径里有引号、反斜杠、控制字符或首尾空白时直接拒绝，`%` 转义为 `%%`。已经部署的 unit 不会被改写，需要手动去掉引号。

## 1.5.0

验证日期：2026-10-27。底座升级到 1.5.0；创意工坊新增官方作品「Claude 娘」2.0.0；内置插件均未改动。

底座变更：
- 运行中引导：任务运行时，输入区的发送按钮旁出现「引导」，按 <kbd>Enter</kbd> 或点它都会把补充要求送进正在运行的任务（`POST /api/sessions/:id/steer`），不用停下任务重来。工作台把它作为带 `uuid` 的 `user` 消息写进 CLI 输入，CLI 在下一次工具调用之间交给模型；Claude 已经在写最后回复时，本轮结束后立刻接着处理。
- 页面上引导显示为虚线气泡和「待送达 / 已送达 / 未送达」标签，状态来自 CLI 的 `command_lifecycle` 帧。还有引导未送达时工作台不关闭 CLI 输入；任务停止或进程退出时未送达的引导标为「未送达」。
- 引导记在当前这一轮里：执行过程侧栏、计时、待办、复制回复、长会话移出历史都不会把它当成新一轮的开头。
- CLI 刚启动、这一轮正在收尾，或 CLI 不报告命令状态时，接口返回 409 并提示稍后再发或等本轮结束后直接发送。请求带 `requestId` 去重，重复提交不会发两次。

创意工坊：
- 新增「Claude 娘」（`claude-tan` 2.0.0，官方）：立绘桌宠，跟着任务思考、调用工具、等待确认、完成、出错、额度紧张和闲置切换姿势；申请 `activity`、`usage.read`、`storage`，不读取对话内容、不联网。立绘由图像模型按文字描述生成，未使用现有画师作品作参考；同人创作，与 Anthropic 无关。说明见 `workshop/src/claude-tan/README.md`。
- `.gitattributes`：`workshop/src/**` 原本一律按文本处理，作品里的图片会在提交时被删掉 `\r\n` 字节而损坏。现在 `png`、`webp`、`gif`、`jpg`、`jpeg`、`woff2` 按二进制保存。
