# 验证记录

## 1.4.0

验证日期：2026-10-24。底座升级到 1.4.0；内置插件「多账号轮询」「任务续跑」均未改动。

底座变更：
- 多个会话可以并行运行，默认最多 3 个（`WORKBENCH_MAX_RUNS`，设为 `1` 恢复一次只运行一个）；运行锁改为按会话加锁，同一会话的图形对话、终端和文件操作仍互斥。插件启用/重扫和账号池等独占操作仍等待所有任务结束，并在进行中挡住新任务。
- 输入区新增「并行已满」「其他会话等你确认」提示；提示条按种类原位更新，不再反复闪烁；侧栏按最近一次发消息的时间排序。
- 长会话不再有 1000 条消息上限：超过 600 条时把较早的完整轮次移到 `<DATA_DIR>/sessions/<id>.history.jsonl`，页面显示「较早的 N 轮对话已移出页面」，消息与工具计数包含已移出部分，导出会话仍包含完整记录。
- 官方 CLI 进程：跟踪所有后台任务（不只子代理），通过 `CLAUDE_CODE_EMIT_SESSION_STATE_EVENTS` 判断一轮真正结束后再关闭输入；成功返回结果后被工作台结束的进程（退出码 143 等）不再记为失败。
- 依赖：`body-parser` 2.3.0 → 2.4.0，修复 `npm audit` 报告的高危漏洞。

### 已完成

- `npm ci`：依赖安装成功。
- `npm test`：216 项全部通过，无跳过（Linux，Node 20.20.2）。新增并行上限、同会话互斥、独占插件操作阻挡并行任务、各账号配置目录互不干扰、结果后被结束的进程、长会话移出与导出等回归。
- `npm run build`：Monaco 主包及 worker 构建成功。
- `npm run workshop:build -- --check`：目录与源码一致（6 个插件、2 款皮肤）。
- `npm audit --omit=dev`：0 漏洞（检查时快照）。
- `git diff --check`：通过；变更文件未发现 Token、私钥、运行数据或账号凭据。
- 在临时目录用模拟 CLI 启动工作台，用无头浏览器检查：3 个任务并行时第 4 个会话显示上限提示且发送按钮禁用，停止其中一个后恢复可发送；运行中会话的执行过程侧栏与后台任务；302 轮的长会话显示移出提示、计数 604、导出包含全部 604 条消息；侧栏排序和手机布局。页面无脚本错误。

### 验证边界

没有用真实 Claude 账号调用模型，也没有在真实账号上验证多个任务并行时的额度消耗与限流表现。CLI 的会话状态事件按官方 CLI 的输出格式模拟。并行任务会同时占用内存，小内存服务器建议把 `WORKBENCH_MAX_RUNS` 调低。
