# Claude 娘

住在工作台右下角的立绘桌宠。橙色长发、头顶呆毛、星芒发饰，跟着任务一起忙：

- **任务开始**：托着下巴思考，头顶冒出思考泡泡
- **调用工具**：抱着笔记本敲代码，飘出 `</>`、`{ }`
- **等你确认**：举手提问，头上一个问号
- **任务完成**：欢呼跳起来，撒出小星星和爱心
- **出错 / 额度紧张**：难过或担心，劝你歇一歇
- **十分钟没动静**：抱着星星睡着了

平时会眨眼、说话时会张嘴、偶尔东张西望。点她（或在命令面板里「摸摸 Claude 娘的头」）会害羞地笑，好感度慢慢从「初识」涨到「挚友」。

## 权限

| 权限 | 用途 |
| --- | --- |
| `activity` | 知道任务何时开始、调用了什么工具、何时等待确认、完成或出错，切换对应的姿势 |
| `usage.read` | 额度用到 80% / 95% 时提醒你 |
| `storage` | 记住好感度和上次见面的时间 |

不读取对话内容，不联网。

## 关于形象

「Claude 娘」是社区里流传的 Claude 拟人形象，本作品是同人创作，与 Anthropic 无关，也未获其认可。立绘由图像模型按文字描述（发色、呆毛、星芒发饰、奶油色连衣裙配黑色束腰）生成，没有使用任何现有画师的作品作为参考图；各个姿势是在同一张母图上编辑出来的，眨眼、说话、表情是从对应姿势上裁下的小块差分。
